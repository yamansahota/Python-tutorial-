Lesson 01

    
Variables & storing data

    
A variable is just a labeled box. You put something in it, and Python remembers it by name.

    

      

        
        this is the box
        
name = "Aanya"
age = 21
is_student = True

# print() shows the value
print(name, age)

        

          
          

        

      

      

        
A variable is created the moment you assign it with =. Python figures out the type on its own — no need to declare it upfront.

        
    
          
  • Strings — text, wrapped in quotes: "Aanya"
    • 
          
  • Integers — whole numbers: 21
    • 
          
  • Booleans — True or False
    • 
        

      

    

  


  

    
Lesson 02

    
Making decisions

    
Programs need to branch. if / elif / else lets your code choose a path based on a condition.

    

      

        
age = 17

if age >= 18:
    print("You can vote")
elif age >= 13:
    print("You're a teenager")
else:
    print("Still a kid")

        

          
          

        

      

      

        
Python checks conditions top to bottom and runs the first block that's True. Everything else is skipped.

        
Notice the indentation — Python uses it instead of curly braces to mark what belongs inside a block.

      

    

  


  

    
Lesson 03

    
Repeating yourself, without repeating yourself

    
Loops run a block of code multiple times so you don't have to copy-paste it.

    

      

        
        runs 3 times
        
for i in range(3):
    print("Lesson", i + 1)

# while loops repeat until
# a condition becomes False
count = 0
while count < 2:
    print("still going")
    count += 1

        

          
          

        

      

      

        
for loops are best when you know how many times to repeat, or you're going through items one by one.

        
while loops keep going as long as a condition stays true — useful when you don't know the count in advance.

      

    

  


  

    
Lesson 04

    
Functions — reusable recipes

    
A function packages up a set of steps under a name, so you can call it whenever you need it.

    

      

        
def greet(name):
    return f"Hello, {name}!"

message = greet("Rohan")
print(message)

        

          
          

        

      

      

        
def starts a function definition. name is a parameter — a placeholder for whatever value gets passed in.

        
return sends a value back to wherever the function was called, so you can store or reuse it.

      

    

  


  

    
Lesson 05

    
Lists — many values, one name

    
A list holds an ordered collection of items, and you can loop over it, add to it, or grab items by position.

    

      

        
fruits = ["mango", "fig", "kiwi"]

print(fruits[0])       # first item
fruits.append("pear")  # add to the end

for fruit in fruits:
    print(fruit)

        

          
          

        

      

      

        
Lists are zero-indexed — the first item is at position 0, not 1.

        
.append() is a method that modifies the list in place, adding a new item to the end.
