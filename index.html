variables.py

Variables & data types

A variable is just a name attached to a value. Python figures out the type of that value on its own — you never declare it up front.

variables.py
age = 21            # int
gpa = 8.6            # float
name = "Yaman"       # str
is_enrolled = True   # bool
subjects = ["DBMS", "AI"]  # list
marks = {"AI": 88}     # dict

control_flow.py

if / else & loops

Control flow is how a program makes decisions (if) and repeats work (for, while) instead of running top to bottom every time.

if_else.py
marks = 72
if marks >= 75:
    print("Distinction")
elif marks >= 60:
    print("First class")
else:
    print("Keep going")
for_loop.py
for i in range(5):
    print(f"lap {'{i}'}")
# range(5) → 0,1,2,3,4

functions.py

Functions

A function packages a block of logic under a name, so you can reuse it with different inputs instead of retyping the code.

functions.py
def calculate(a, b, op):
    if op == "add":
        return a + b
    elif op == "subtract":
        return a - b
    elif op == "multiply":
        return a * b
    elif op == "divide":
        return a / b

Quick check

1. What keyword sends a value back out of a function?

return hands a value back to whoever called the function; print only displays it.

2. In def calculate(a, b, op):, what are a, b, op called?

They're parameters — placeholders that get filled in with real values when the function is called.
